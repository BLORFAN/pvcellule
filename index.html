Du photon à l'électron, et retour dans la cellule

Photon Électron (−) Trou (+) Sens conventionnel du courant I
  1. 1Le photon arrive
  2. 2L'électron se libère
  3. 3La jonction le pousse
  4. 4La grille le collecte
  5. 5Lampe en série
  6. 6Retour à la borne +
  7. 7Le trou est comblé

Un circuit en série

Cellule (borne −) → interrupteur → lampe → ampèremètre → cellule (borne +)

Il n'y a qu'une seule boucle : les électrons traversent tous les dipôles l'un après l'autre. L'intensité du courant est donc la même partout dans le circuit. Si on ouvre l'interrupteur, la boucle est coupée : plus de courant, la lampe s'éteint.
